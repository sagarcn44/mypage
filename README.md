# Sagar C N — Professional Profile Demo

A single-page, responsive profile inspired by professional networking profile layouts. It uses Node.js's built-in HTTP server and has no third-party dependencies.

## Run locally

1. Install Node.js 18 or newer.
2. Open a terminal in this folder.
3. Run `npm start` (or `node server.js`).
4. Visit http://localhost:3000.

To use a different port: `PORT=8080 npm start` (PowerShell: `$env:PORT=8080; npm start`).

## Customize

Edit the profile copy and sections in `server.js`. The page uses initials rather than copying a LinkedIn profile photo. Some experience details are intentionally generic; replace them with your exact role title, dates, and responsibilities before publishing.
